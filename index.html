Ключ Gemini API

Ключ создаётся бесплатно: aistudio.google.com/apikey. Он хранится только в этом браузере на этом устройстве и отправляется только в Google (Gemini API).

Журнал и диагностика

Подробный журнал (подключения, таймауты, ошибки) хранится только в памяти страницы. Тексты в него не пишутся, только их длина.

Установка на iPhone / Mac

iPhone (Safari): кнопка «Поделиться» → «На экран “Домой”». Mac (Safari): «Файл» → «Добавить в Dock». Chrome / Edge: значок «Установить» в адресной строке. Нужен адрес с https:// (или localhost), иначе браузер не даст доступ к микрофону.

Ограничения: на iPhone звук и микрофон работают, пока экран включён и приложение открыто; кнопка «без звука» на боковой стороне может заглушать звук.

Прежде чем начать

Приложение озвучивает и переводит с помощью Google Gemini. Поэтому:

  • введённые вами тексты и звук с микрофона передаются в Google (Gemini API) для обработки;
  • вы используете свой ключ API, он хранится только на этом устройстве;
  • условия и хранение данных определяет Google; для бесплатных ключей данные могут использоваться для улучшения сервисов Google.

Не отправляйте конфиденциальную информацию. Нажимая «Согласен», вы разрешаете такую передачу.
