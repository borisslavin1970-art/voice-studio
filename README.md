# Голосовая студия — веб-версия (PWA)

Та же студия и тот же переводчик, но в браузере: работает на iPhone, iPad, Mac, Windows и Android, устанавливается
на экран «Домой» как приложение. Магазин приложений не нужен. Свой ключ Gemini API вводится в «Настройках».

## Запуск на своём компьютере

```
serve_web.bat          (Windows;  macOS/Linux: sh serve_web.sh)
```

Откроется `http://localhost:8080/`. На `localhost` браузер разрешает микрофон и без https. Порт занят — `serve_web.bat 8091`.

## Как выложить, чтобы пользоваться с iPhone

Браузер даёт доступ к микрофону только на страницах с **https://**. Папка `web` — набор статических файлов,
их можно разместить бесплатно:

- **Cloudflare Pages / Netlify** — создайте проект и перетащите папку `web` (Netlify: app.netlify.com/drop);
- **GitHub Pages** — загрузите содержимое `web` в репозиторий и включите Pages;
- любой свой хостинг со статикой и сертификатом https.

Ничего серверного не нужно: ключ хранится в браузере пользователя, а запросы идут напрямую в Google.
Полученный адрес откройте на iPhone в Safari → «Поделиться» → «На экран “Домой”».

## Ключ и приватность

- Каждый пользователь вводит **свой** ключ (aistudio.google.com/apikey). Он лежит в `localStorage` этого браузера и
  уходит только в Google. Не публикуйте страницу со своим ключом внутри кода.
- При первом запуске показывается согласие: текст и звук передаются в Google. Это же понадобится при оформлении
  приложения для App Store (правило Apple 5.1.2(i)).
- Тексты в журнал не пишутся, только длина. Журнал — в памяти страницы: «Настройки» → «Скопировать/Скачать журнал».

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html`, `style.css` | интерфейс (вкладки «Студия», «Переводчик», «Настройки») |
| `app.js` | логика окна, микрофон, журнал |
| `live.js` | соединение с Gemini Live: подготовка заранее, переподключение, таймауты, повтор, обновление сессии |
| `audio.js`, `mic-worklet.js` | воспроизведение 24 кГц и запись микрофона 16 кГц (AudioWorklet) |
| `prompts.js` | тексты инструкций модели (порт Python-версии) |
| `data.js` | голоса, акценты, языки — **генерируется** `python make_web_data.py` из Python-модулей |
| `sw.js`, `manifest.webmanifest`, иконки | установка как приложения и работа оболочки без сети |

После правки `voice_catalog.py`, `accents.py` и т. п. запустите `python make_web_data.py`, чтобы обновить `data.js`.

## Ограничения

- **iPhone / iPad:** звук и микрофон работают, пока экран включён и приложение на переднем плане; при блокировке экрана
  соединение прерывается (при возврате приложение переподключается само). Боковой переключатель «без звука» может
  глушить воспроизведение; если звука нет, проверьте его.
- Выбор конкретного микрофона недоступен: используется микрофон по умолчанию.
- Эхо: в колонках модель может услышать себя, поэтому микрофон «глохнет» на время перевода; в наушниках отметьте
  «Я в наушниках».
- Эхоподавление и шумоподавление включает сам браузер.

## Проверка

Проверено на тестовом сервере и реальном Gemini API (ключ в адресе, бинарные кадры, ответ на неверный ключ), в Chromium:
озвучка, настройки и акценты, переводчик, оба движка, микрофон на синтетическом звуке, сбои (обрыв, молчание модели,
неверный ключ), мобильная вёрстка. **Не проверено** на реальных iPhone/Safari и с настоящим микрофоном.

Параметр `?mock=ws://адрес` в адресе страницы направляет её на тестовый сервер вместо Google (нужен только для разработки).
